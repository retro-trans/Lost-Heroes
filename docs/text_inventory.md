# Text inventory: Lost Heroes (Japan) (v1.01), PSP

Generated by `tools/count_text.py`. Raw numbers: `work/source/text_count.json` (local only).

## Where the text lives

| Layer | Format | Tool |
|---|---|---|
| UMD image | ISO9660 | `tools/iso_extract.py` |
| `PSP_GAME/USRDIR/ALLRES.PCK` | "2NBF" archive (10,072 entries) | `tools/pck_extract.py` |
| `*.cmp` inside it | ZIP, often holding another 2NBF `.pck` | `tools/walk_assets.py` (recursive) |
| `*.mbb` (+ 25 quest tables named `.pck`) | TBB1 container → MTBL message tables | `tools/mbb.py` |
| Font | `Font/Font14.tpc` (4 pages), `Font10.tpc` (2), `FontStaff.tpc` (1): 256×512 4bpp swizzled, 14×16 cells, 18 per row | `tools/font_render.py` |

The text is **not Shift-JIS**. Each character is a u16 = font glyph index + 1:

- `0x0001–0x0040`: space, `?`, 0–9, A–Z, a–z
- `0x0041–0x00E9`: hiragana and katakana
- `0x00EA–0x017C`: full-width symbols and Japanese punctuation
- `0x017D–~0x0900`: kanji in a custom order (needs a transcribed table)
- `0x8000–0x80FF`: control codes (`0x8001` = line break)
- other values ≥ `0x3000`: raw Unicode (about 3% of characters, mainly item, skill and library text)

`PSP_GAME/INSDIR/ALLRES.PCK` is a PGD-encrypted install copy. It is not scanned here.
